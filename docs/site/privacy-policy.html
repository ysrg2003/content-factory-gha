Privacy Policy

Effective date: 2026-08-14

This page is an operational draft for developer-portal configuration and is not legal advice. Have a qualified attorney review it before relying on it.

1. Who controls processing

The person or organization that owns and runs the repository and connects the external accounts controls the workflow configuration and submitted content. Questions can be raised in the public repository issue tracker. Do not put passwords, tokens, private video links, or personal information in an issue.

2. Information processed

The project does not intentionally require a personal photograph, contact list, unrelated files, or unrelated account passwords. A connected platform may process information under its own policy when you authorize an API request or publish content.

3. How processing works

GitHub Actions receives a manually submitted video URL and destination selections. FFmpeg and Whisper process media in the runner. The AI Provider Router may send metadata-generation inputs to a configured provider such as Gemini or Hugging Face. The selected YouTube, Meta, or TikTok API may receive media and publication metadata required by that platform. A platform is contacted only when its publication input is enabled.

4. Third-party recipients

Depending on enabled integrations, processing may involve GitHub, Google Gemini, Hugging Face, Google/YouTube, Meta, and TikTok. Each provider controls its own retention, security, moderation, and international processing under its published rules.

5. Credentials and security

Credentials must remain in GitHub Actions Secrets or an ignored local file during one-time OAuth setup. They must never be committed, pasted into an issue, or printed in logs. The TikTok helper writes a local token response to .tiktok/tokens.json, which is excluded by .gitignore. The browser-cookie fallback is disabled by default and must be treated as account-equivalent access.

6. Retention and deletion

Generated files and the AI Router state database are retained in a GitHub Actions Artifact for the workflow’s configured period, currently one day unless GitHub or repository settings impose a different limit. Local downloads, token files, cookies, and temporary media should be deleted after use and must not be committed. Deleting a file does not revoke an issued token; revoke it with its provider.

7. Choices and sensitive information

The operator chooses the media, AI provider chain, and destination platforms. Do not submit another person’s personal data or media without the required permissions. Do not submit sensitive personal, health, financial, government-ID, children’s, or confidential business information without appropriate legal basis and safeguards. The project is not represented as a service designed for children.

8. Changes

Updates will be published in this repository with a new effective date. Review this policy whenever the workflow adds a provider, destination, or data-retention behavior.
